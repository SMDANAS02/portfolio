VSB-APEX

An open-source departmental analytics platform that turns 200+ scattered student records into one live, queryable dashboard for the IT department.

React 18FastAPIPostgreSQL · Neon AlembicRender + Vercel
GitHub Repo Ask about it
the problem

Academic data was everywhere except one place.

The IT department tracked student performance, attendance, and academic history across scattered spreadsheets and disconnected records. Nobody had a single, reliable view of how 200+ students were actually doing, and any answer meant manually cross-referencing files.

what I built

An analytics dashboard the department actually maintains.

  • A React 18 frontend backed by a FastAPI service, giving the department a live, searchable view of academic data across the entire student body.
  • Schema evolution managed through Alembic migrations on Neon's serverless Postgres, so the data model can change without breaking production.
  • CI/CD wired through Render and Vercel, cutting manual sync effort by roughly 70% compared to the old spreadsheet workflow.
  • Multi-contributor development with protected file conventions and a structured PR review process, since this is now an open-source, actively maintained tool.
under pressure

A 2-hour production fix.

A passlib/bcrypt version mismatch broke authentication in production. Instead of waiting on an upstream fix, I rewrote the auth layer directly against bcrypt with SHA-256 pre-hashing, restoring login within two hours of the report coming in.
