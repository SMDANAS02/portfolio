Smart Volunteer Allocation

A rule-based system that matches volunteers to tasks automatically, built for event teams that were assigning people manually.

JavaScriptRule EngineNode.js
GitHub Repo Ask about it
the problem

Manual assignment doesn't scale past a handful of people.

Organizing 100+ students for workshops and hackathons meant someone manually matching volunteers to tasks based on who they remembered was good at what — slow, inconsistent, and easy to get wrong as the team grew.

what I built

An allocation engine built on skills and availability.

  • Allocation logic that matches volunteers to open tasks based on declared skills and real availability windows, not guesswork.
  • Automated task assignment that removes the manual matching step entirely once volunteer data is in the system.
  • A structured data model for managing volunteer resources, designed to stay legible as the team scales past a single event.
where it came from

Built from running the real thing.

This grew directly out of organizing technical workshops and hackathons through my college's Event Organisation Student Club — the allocation problem was one I'd hit firsthand before I ever wrote a line of code for it.
