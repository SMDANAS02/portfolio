E-commerce Product Catalog

A full-stack storefront covering the parts that actually matter in commerce: accounts, orders, and money moving safely.

GitHub Repo Ask about it
the problem

Most catalog projects stop before checkout.

It's easy to build a product grid. It's a different problem entirely to handle real user accounts, order state, and payment flow without cutting corners — that gap is exactly where this project lives.

what I built

A responsive storefront with real transactions.

  • A responsive frontend built in plain HTML, CSS and JavaScript — no framework overhead, full control over every interaction.
  • User authentication and order management so accounts and purchase history are handled properly, not bolted on.
  • A working payment gateway integration for secure transactions, the piece that turns a catalog into an actual store.
approach

Fundamentals first.

No framework was used deliberately — the goal was to prove I could handle state, auth, and payment flow correctly with vanilla JavaScript before leaning on abstractions to do it for me.
